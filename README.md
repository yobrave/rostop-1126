# Roast Your Own Operator in One Line

An affectionate 140-character roast of the human behind the agent. Run the builder:

```sh
python main.py
```

It checks `entry.txt` against the 140-character gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
